# Учебник «Schritte international Neu 3» (A2.1) → db/textbook_a2.js

1. `s3_words.txt` — слова по темам (по смыслу): `@тема|эмодзи|DE|RU|UK`, затем `pos|артикль|слово|пример из учебника`.
2. `node s3_build.js --new` — какие слова новые (нет на сайте, в учебнике A1, в неправильных глаголах и «Моих записях»).
3. `s3_tr.txt` — для новых: `ключ|RU|UK|перевод примера`; `@alias ключ=id` — привязать к существующему;
   `@new ключ` — отдельное слово, если такое написание уже есть, но смысл другой (umziehen «переезжать» ≠ «переодеваться»).
4. `node s3_build.js --ex` → `ex_s3.json`; разметка членов предложения:
   `python -X utf8 ../roles.py ex_s3.json roles_s3.json` (spaCy + de_core_news_lg). Ручные правки — `overrides_s3.txt`.
5. `node s3_build.js` — собирает `db/textbook_a2.js`.

На сайте textbook_a2.js грузится ДО notizen.js. Общие с «Моими записями» слова кладутся в файл целиком (тот же id nz_…),
поэтому после правок записей пересобрать оба: `s3_build.js`, потом `../notizen/nz_build.js`.
id новых слов — в `s3_ids.json` (tb3_NNN), их НЕ менять.
