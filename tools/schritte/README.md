# Учебник «Schritte international Neu» → db/textbook.js

1. `tb_words.txt` — слова по урокам (с фото Lernwortschatz): `pos|артикль|слово|пример из учебника`,
   заголовок урока: `# N|Название DE|RU|UK|эмодзи`. Новые слова/уроки дописывать в конец урока.
2. `node tb_match.js` — сверяет со словами сайта (db/words.js), пишет `tb_match.json`, выводит новые слова.
3. `tb_tr.txt` — для новых слов: `ключ|перевод RU|перевод UK|перевод примера`;
   `@alias ключ=id` — привязать к уже существующему слову, `@new ключ` — сделать отдельным словом.
4. `tb_topics.txt` — в какой теме (по смыслу) стоит каждое слово; build проверяет, что каждое слово ровно в одной теме.
5. `overrides_tb.txt` — ручные правки цветной разметки примеров (`roles_tb.json` — авторазметка spaCy).
6. `node tb_build.js` — собирает `db/textbook.js`.

id новых слов хранятся в `tb_ids.json` (ключ → id) — их НЕЛЬЗЯ менять, иначе прогресс пользователей
перепутается. Новые слова получают следующий свободный номер автоматически.
